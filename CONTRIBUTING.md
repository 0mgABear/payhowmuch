# Contributing to PayHowMuchBot

Thanks for your interest! This is a personal project but contributions are welcome.

## Ways to Contribute

- **Bug reports** — open an issue describing what happened and how to reproduce it
- **Feature suggestions** — open an issue with your idea
- **Pull requests** — fork the repo, make your changes, and open a PR

## Guidelines

- Keep changes focused — one fix or feature per PR
- Test your changes before submitting
- Write clear commit messages

## Contact

Reach out via [commonertech.dev](https://commonertech.dev) if you have questions.
